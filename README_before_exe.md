# Versões históricas

Os arquivos recebidos mostram duas linhas do produto: uma versão preparada para executável e outra atualizada com filtro por mês e ano para download em lote de Avisos e Recibos. Como o conteúdo disponível estava parcial e continha uma URL corporativa, a branch publica uma implementação reconstruída, parametrizada e sem detalhes internos.
