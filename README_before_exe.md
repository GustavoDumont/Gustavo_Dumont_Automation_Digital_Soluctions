# Versões históricas

Os três arquivos recebidos foram analisados como evidência da evolução do produto. Eles não foram copiados para esta branch porque incluem endereços internos, seletores específicos e, em duas versões, credenciais em texto puro.

- `App_UNICO.py`: aplicação inicial multi-candidato, distribuída em EXE.
- `automacao_unico.py`: versão mais robusta para documentos, assinaturas e fichas.
- `Automacao_Unico_Assinaturas.py`: worker especializado em assinaturas concluídas.

A implementação pública preserva a arquitetura geral sem permitir acesso direto ao ambiente corporativo.
