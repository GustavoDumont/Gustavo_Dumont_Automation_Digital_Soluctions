## Convenção para novas branches

Cada nova branch deve possuir, no mínimo:

- `README.md` com problema, solução, funcionamento e resultado;
- `.gitignore` adequado aos dados tratados;
- `SECURITY.md` quando houver dados pessoais, financeiros ou acesso a portais;
- dependências e instruções de execução, quando houver código;
- indicação clara do que está concluído e do que permanece em desenvolvimento;
- link de retorno para a branch `main`.

## Link de retorno sugerido

Insira no início ou no final de cada README de projeto:

```markdown
[← Voltar ao portfólio principal](https://github.com/GustavoDumont/Gustavo_Dumont_ConcrematCCCC)
```
