# Segurança e privacidade

## Dados proibidos no repositório

- exportações reais do SharePoint;
- planilhas atualizadas com dados de colaboradores;
- CPFs, telefones, e-mails, matrículas ou nomes reais;
- URLs internas, tokens, credenciais ou segredos;
- relatórios de auditoria com dados operacionais.

## Uso seguro

O processamento do dashboard ocorre no navegador, mas isso não substitui controles de acesso. Use somente arquivos autorizados, feche a página após o uso e revise qualquer relatório antes do compartilhamento.

Vulnerabilidades devem ser reportadas sem anexar dados pessoais ou arquivos operacionais.
