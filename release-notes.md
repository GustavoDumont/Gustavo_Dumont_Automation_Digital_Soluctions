# Notas de versão

## Versão distribuída

Aplicação desktop empacotada como executável portátil e utilizada pelo núcleo administrativo.

## Versão experimental 2.1

Inclui correções de interface e ampliações como conversões adicionais, edição, assinatura, proteção, remoção autorizada de senha, compressão, descompressão e renomeação assistida. Não homologada para distribuição geral.
