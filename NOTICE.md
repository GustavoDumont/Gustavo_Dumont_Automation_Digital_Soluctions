# Aviso de uso e confidencialidade

Este repositório apresenta uma versão anonimizada para portfólio de uma solução criada em contexto profissional.

- Não contém credenciais, documentos fiscais, contratos, contatos ou endereços corporativos reais.
- A integração original não é disponibilizada para uso em produção.
- A publicação e o uso devem respeitar contratos, políticas internas, propriedade intelectual e autorizações das organizações envolvidas.
- Não utilize esta automação em sistemas de terceiros sem autorização formal.

Antes de tornar o repositório público, obtenha a autorização aplicável do titular do código e das regras de negócio.
